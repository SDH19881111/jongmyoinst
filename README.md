# 종묘제례악 놀이터

스크래치 작품 「종묘제례악 악기 연주」를 웹으로 옮기고, 아이들이 직접 제례악을 지어 보는 작곡 화면을 더한 버전입니다.

- `index.html` — 첫 화면. 두 활동 중 하나를 고릅니다.
- `play.html` + `app.js` — **악기 연주해 보기**: 편종·편경·축·박·어·절고 여섯 악기를 눌러서(편종·편경은 키보드 A~J로도) 연주합니다.
- `maker.html` + `maker.js` — **제례악 작곡가 되기**: 크롬 뮤직 랩 송메이커처럼 칸을 눌러 악기 소리를 찍고 연주합니다.
  - 한 칸 = 한 박, 4박 = 한 마디, 길이 4·8·12·16마디
  - 재생/멈춤(Space), 반복, 빠르기, 되돌리기(Ctrl+Z), 모두 지우기, 예시 곡
  - 누른 채 끌어서 여러 칸 채우기/지우기, 악기 그림·음 이름을 누르면 미리 듣기
  - 작품 이름·지은이와 함께 브라우저에 자동 저장, 「링크 복사」로 곡을 주소에 담아 공유

설치·빌드 없음. 로컬 실행: `python -m http.server` 후 http://localhost:8000
